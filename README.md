# Vanilla Finest files

Unmodified copies of mods used by the [Vanilla Finest](https://modrinth.com/modpack/vanilla-finest-survival)
modpacks that are not on Modrinth. Modrinth modpacks may only download files from Modrinth, GitHub or
GitLab, so these files are kept here instead of inside each modpack. The packs link each file at a
fixed commit (raw.githubusercontent.com), and the Modrinth App downloads it when a pack is installed.

The files are the authors' own builds, not changed in any way. Each one stays under its author's
licence (each Traveler's Titles jar also contains its own licence file). When a mod becomes available on Modrinth, the packs switch to it and its copy here is no
longer needed.

| Traveler's Titles 1.0.0 (Fabric: 26.3, 26.2, 26.1, 1.21.11) | Astryxion | LGPL-3.0 ([text](LICENSES/LGPL-3.0.txt), with [GPL-3.0](LICENSES/GPL-3.0.txt)) | [astryxion/Travelers-Titles](https://github.com/astryxion/Travelers-Titles) | [mods/travelers-titles/1.0.0](mods/travelers-titles/1.0.0) |

If you are the author of one of these mods and would rather it was not hosted here, please open an
issue and it will be removed. Files already linked by a released pack version stay reachable at
their commit until then.
