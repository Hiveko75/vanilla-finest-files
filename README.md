# Vanilla Finest files

Unmodified copies of mods used by the [Vanilla Finest](https://modrinth.com/modpack/vanilla-finest-survival)
modpacks that are not on Modrinth. Modrinth modpacks may only download files from Modrinth, GitHub or
GitLab, so these files are kept here, in GitHub releases, instead of inside each modpack. The Modrinth
App downloads them when a pack is installed.

The files are the authors' own builds, not changed in any way. Each one stays under its author's
licence. When a mod becomes available on Modrinth, the packs switch to it and its copy here is no
longer needed.

If you are the author of one of these mods and would rather it was not hosted here, please open an
issue and it will be removed.
